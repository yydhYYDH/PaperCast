## 排印

- 正文 15px / line-height 1.7；次要说明 12.5–13px；微标签 11–12px。
- 标题：页面 `h1` 用衬线 22–24px；卡片/区块标题衬线 15–16px；正文里的小标题用 `--ink` + 常规字重（不靠加粗）。
- 数字：`font-variant-numeric: tabular-nums` **只用在数字列**（表格、关键数字），不要给整段用。
- 长文本 `max-width: 65–72ch`，中文段落行高 ≥1.7。

## 间距与布局

- 一份刻度：4 / 8 / 12 / 16 / 24 / 32 / 48；页面内边距 28–32px，模块间距 16–24px。
- 面板 = 白底 + 1px `--hairline` + 圆角 12px + 内边距 18–20px；**不用阴影**表达层级，用描边与留白。
- 工作台：`grid-template-columns: minmax(0, 1fr) 300px`，对话列居中 760px；≤1180px 收起右栏。
- 空状态：一句解释 + 一个动作按钮，居中、留白足够，不要插画。

## 组件配方

- 主按钮：近黑底 + 白字，圆角 8px，padding 9px 16px；次按钮：白底 + 1px 描边；危险按钮：白底 + 红字，只在真危险时用。
- 状态 pill：粉彩底 + 深字 + 12px，小圆点 6px 表示在线/进行中（running 用轻呼吸动画，别闪烁）。
- 折叠条（`.fold`）：**折叠条本身必须是一句结论**（「这台机器上的 5 个服务都在跑。」），右侧 `展开/收起`。
- 行式列表优于卡片网格：`.lines li` 一行放「名字 + 一句状态 + 一个数字 + 一个动作」，分隔线用 `--line-soft`。
- 对话气泡：用户右对齐浅灰底；助手左侧，衬线首字徽章 + 名字 + 正文；产物用 pill（文/版/图/影/数/字/讲）挂在这一条下面。
- 日志：`.logbox` 等宽 12px、`max-height: 340px`、可滚动，错误/警告用 `--tone-red-fg`/`--tone-amber-fg`。

## 文案模板

- 结论句：「已发出 3 条内容，合计 1,204 个播放、86 个点赞。」／读不到：「现在还读不到任何数字 —— 小红书 MCP 报告未登录…」
- 服务句：「这台机器上的 5 个服务都在跑。」／掉队：「5 个服务里有 1 个没在跑：B 站通道。」
- 运行句：「一共跑过 11 次，5 次完成，1 次等你确认，5 次没成功。想看每一次的细节去『运行记录』。」
- 闸门提示：「真正的发布要你点头，我不会自己发。」
